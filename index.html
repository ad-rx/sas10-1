📘 Bagian 1 — Pilihan Ganda Biasa (Soal 1–30)
Soal 1
Nilai dari $3^4 \times 3^2 = \ldots$
Gunakan sifat $a^m \times a^n = a^{m+n}$.
$3^4 \times 3^2 = 3^{4+2} = 3^6 = 729$
Jawaban: B
Soal 2
Nilai dari $5^6 : 5^3 = \ldots$
Gunakan sifat $\dfrac{a^m}{a^n} = a^{m-n}$.
$5^6 : 5^3 = 5^{6-3} = 5^3 = 125$
Jawaban: B
Soal 3
Nilai dari $\left(3^2\right)^3 = \ldots$
Gunakan sifat $\left(a^m\right)^n = a^{m \times n}$.
$\left(3^2\right)^3 = 3^{2 \times 3} = 3^6 = 729$
Jawaban: D
Soal 4
Nilai dari $36^{1/2} = \ldots$
Ingat $a^{1/2} = \sqrt{a}$.
$36^{1/2} = \sqrt{36} = 6$
Jawaban: B
Soal 5
Nilai dari $27^{2/3} = \ldots$
Gunakan $a^{m/n} = \left(\sqrt[n]{a}\right)^m$.
$27^{2/3} = \left(\sqrt[3]{27}\right)^2 = 3^2 = 9$
Jawaban: C
Soal 6
Jika $4^x = 64$, maka nilai $x$ adalah …
Ubah kedua ruas ke basis yang sama: $4 = 2^2$ dan $64 = 2^6$.
$4^x = 64 \Rightarrow \left(2^2\right)^x = 2^6 \Rightarrow 2^{2x} = 2^6$
$2x = 6 \Rightarrow x = 3$
Jawaban: B
Soal 7
Nilai dari ${}^{3}\log 243 = \ldots$
${}^{3}\log 243 = x \Leftrightarrow 3^x = 243$.
Karena $243 = 3^5$, maka $x = 5$.
Jawaban: C
Soal 8
Nilai dari ${}^{5}\log 125 = \ldots$
${}^{5}\log 125 = x \Leftrightarrow 5^x = 125$.
Karena $125 = 5^3$, maka $x = 3$.
Jawaban: B
Soal 9
Nilai dari $\log 10000 = \ldots$
$\log$ tanpa basis berarti $\log_{10}$.
$\log 10000 = {}^{10}\log 10^4 = 4$
Jawaban: D
Soal 10
Nilai dari ${}^{2}\log 16 + {}^{2}\log 8 = \ldots$
${}^{2}\log 16 = 4$ karena $2^4 = 16$.
${}^{2}\log 8 = 3$ karena $2^3 = 8$.
Jumlahnya $= 4 + 3 = 7$.
Jawaban: C
Soal 11
Barisan aritmetika: $4, 9, 14, 19, \ldots$ Beda ($b$) barisan tersebut adalah …
Beda $b = U_2 - U_1 = 9 - 4 = 5$.
Cek: $14 - 9 = 5$ dan $19 - 14 = 5$. Konsisten.
Jawaban: C
Soal 12
Suku ke-12 dari barisan aritmetika $5, 8, 11, 14, \ldots$ adalah …
$a = 5$, $b = 3$, rumus $U_n = a + (n-1)b$.
$U_{12} = 5 + (12-1)\cdot 3 = 5 + 33 = 38$
Jawaban: D
Soal 13
Jumlah 6 suku pertama deret aritmetika $2 + 5 + 8 + \ldots$ adalah …
$a = 2$, $b = 3$, gunakan $S_n = \dfrac{n}{2}\left(2a + (n-1)b\right)$.
$S_6 = \dfrac{6}{2}\left(2\cdot 2 + 5\cdot 3\right) = 3(4 + 15) = 3 \cdot 19 = 57$
Jawaban: C
Soal 14
Barisan geometri: $3, 12, 48, 192, \ldots$ Rasio ($r$) barisan tersebut adalah …
Rasio $r = \dfrac{U_2}{U_1} = \dfrac{12}{3} = 4$.
Cek: $\dfrac{48}{12} = 4$ dan $\dfrac{192}{48} = 4$. Konsisten.
Jawaban: C
Soal 15
Suku ke-4 dari barisan geometri $2, 6, 18, \ldots$ adalah …
$a = 2$, $r = 3$, rumus $U_n = a \cdot r^{n-1}$.
$U_4 = 2 \cdot 3^{3} = 2 \cdot 27 = 54$
Jawaban: C
Soal 16
Jumlah 4 suku pertama deret geometri $2 + 6 + 18 + 54 + \ldots$ adalah …
$a = 2$, $r = 3$, gunakan $S_n = \dfrac{a\left(r^n - 1\right)}{r - 1}$.
$S_4 = \dfrac{2\left(3^4 - 1\right)}{3 - 1} = \dfrac{2(81 - 1)}{2} = 80$
Cek langsung: $2 + 6 + 18 + 54 = 80$. ✔
Jawaban: C
Soal 17
Jumlah deret geometri tak hingga $8 + 4 + 2 + 1 + \ldots$ adalah …
$a = 8$ dan $r = \dfrac{4}{8} = \dfrac{1}{2}$ (karena $|r| < 1$, deret konvergen).
$S_\infty = \dfrac{a}{1 - r} = \dfrac{8}{1 - \frac{1}{2}} = \dfrac{8}{\frac{1}{2}} = 16$
Jawaban: C
Soal 18
Barisan aritmetika dengan suku pertama $7$ dan beda $4$. Suku ke-9 adalah …
$U_n = a + (n-1)b$ dengan $a = 7$, $b = 4$.
$U_9 = 7 + (9-1)\cdot 4 = 7 + 32 = 39$
Jawaban: C
Soal 19
Deret geometri $2 + 4 + 8 + 16 + \ldots$ Jumlah 6 suku pertama adalah …
$a = 2$, $r = 2$.
$S_6 = \dfrac{2\left(2^6 - 1\right)}{2 - 1} = 2(64 - 1) = 126$
Jawaban: C
Soal 20
Suku ke-5 dari barisan geometri $1, 3, 9, 27, \ldots$ adalah …
$a = 1$, $r = 3$.
$U_5 = 1 \cdot 3^{4} = 81$
Jawaban: C
Soal 21
Nilai $\sin 30^\circ$ adalah …
Nilai sudut istimewa: $\sin 30^\circ = \dfrac{1}{2}$.
Jawaban: B
Soal 22
Nilai $\cos 45^\circ$ adalah …
Nilai sudut istimewa: $\cos 45^\circ = \dfrac{1}{2}\sqrt{2}$.
Jawaban: C
Soal 23
Nilai $\tan 60^\circ$ adalah …
$\tan 60^\circ = \dfrac{\sin 60^\circ}{\cos 60^\circ} = \dfrac{\frac{1}{2}\sqrt{3}}{\frac{1}{2}} = \sqrt{3}$.
Jawaban: D
Soal 24
Nilai $\sin 0^\circ$ adalah …
Pada sudut $0^\circ$, ordinat titik pada lingkaran satuan adalah $0$.
Jadi $\sin 0^\circ = 0$.
Jawaban: B
Soal 25
Nilai $\cos 90^\circ$ adalah …
Pada sudut $90^\circ$, absis titik pada lingkaran satuan adalah $0$.
Jadi $\cos 90^\circ = 0$.
Jawaban: B
Soal 26
Segitiga siku-siku $ABC$ siku-siku di $B$. $AB = 6$ cm dan $AC = 10$ cm. Nilai $\sin A$ adalah …
Siku-siku di $B$, maka $AC$ adalah sisi miring dan $AB$ adalah sisi samping sudut $A$.
Cari $BC$ dengan Pythagoras: $BC = \sqrt{AC^2 - AB^2} = \sqrt{100 - 36} = \sqrt{64} = 8$ cm.
$\sin A = \dfrac{BC}{AC} = \dfrac{8}{10} = \dfrac{4}{5}$
Jawaban: B
Soal 27
Nilai $\cos 30^\circ$ adalah …
Nilai sudut istimewa: $\cos 30^\circ = \dfrac{1}{2}\sqrt{3}$.
Jawaban: D
Soal 28
Nilai $\tan 45^\circ$ adalah …
$\tan 45^\circ = \dfrac{\sin 45^\circ}{\cos 45^\circ} = \dfrac{\frac{1}{2}\sqrt{2}}{\frac{1}{2}\sqrt{2}} = 1$.
Jawaban: C
Soal 29
Diketahui $\sin \alpha = \dfrac{5}{13}$ dan $\alpha$ sudut lancip. Nilai $\cos \alpha$ adalah …
Gunakan identitas $\sin^2\alpha + \cos^2\alpha = 1$.
$\cos^2\alpha = 1 - \left(\dfrac{5}{13}\right)^2 = 1 - \dfrac{25}{169} = \dfrac{144}{169}$
Karena $\alpha$ lancip, $\cos\alpha$ positif: $\cos\alpha = \dfrac{12}{13}$.
Jawaban: B
Soal 30
Nilai $\sin 45^\circ + \cos 45^\circ = \ldots$
$\sin 45^\circ = \cos 45^\circ = \dfrac{1}{2}\sqrt{2}$.
$\dfrac{1}{2}\sqrt{2} + \dfrac{1}{2}\sqrt{2} = \sqrt{2}$
Jawaban: B
🧩 Bagian 2 — Pilihan Ganda Kompleks (Soal 31–35)
Soal 31 Pilih semua jawaban benar
Manakah pernyataan berikut yang BENAR?
A. $3^4 = 3 \times 3 \times 3 \times 3 = 81$ → BENAR
B. $4^3 = 4 \times 4 \times 4 = 64$ → BENAR
C. $5^2 = 25$, bukan $10$ → SALAH
D. $2^6 = 64$ → BENAR
E. $6^2 = 36$ → BENAR
Jawaban: A, B, D, E
Soal 32 Pilih semua jawaban benar
Manakah yang bernilai sama dengan $1$?
Sifat penting: $a^0 = 1$ untuk setiap $a \neq 0$.
A. $8^0 = 1$ → BENAR
B. $4^0 = 1$ → BENAR
C. $2^1 = 2$ → SALAH
D. $15^0 = 1$ → BENAR
E. $9^0 = 1$ → BENAR
Jawaban: A, B, D, E
Soal 33 Pilih semua jawaban benar
Manakah yang merupakan barisan aritmetika?
Barisan aritmetika: selisih dua suku berurutan selalu tetap.
A. $7 - 4 = 3$, $10 - 7 = 3$ → beda tetap $3$ → ARITMETIKA
B. $6 - 2 = 4$, $18 - 6 = 12$ → beda tidak tetap (ini geometri, $r = 3$) → BUKAN
C. $15 - 20 = -5$, $10 - 15 = -5$ → beda tetap $-5$ → ARITMETIKA
D. $4 - 1 = 3$, $9 - 4 = 5$ → beda tidak tetap → BUKAN
E. $11 - 6 = 5$, $16 - 11 = 5$ → beda tetap $5$ → ARITMETIKA
Jawaban: A, C, E
Soal 34 Pilih semua jawaban benar
Pernyataan yang benar untuk barisan $2, 6, 18, 54, \ldots$ adalah …
Diketahui $a = U_1 = 2$ dan $r = \dfrac{6}{2} = 3$.
A. $r = 3$ → BENAR
B. $U_3 = 18$ (sesuai barisan) → BENAR
C. $U_4 = 54$ (sesuai barisan) → BENAR
D. $a = 2$ → BENAR
E. $U_5 = 2 \cdot 3^4 = 2 \cdot 81 = 162 \neq 108$ → SALAH
Jawaban: A, B, C, D
